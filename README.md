## 🌟 About the Project

Meet **Jarvis**, a voice assistant built to make everyday computer interactions smarter and easier.

Instead of typing every command, simply speak the wake word **"Jarvis"** and let your assistant take it from there.

This project combines Python, speech recognition, text-to-speech, web automation and Google's Gemini AI to create an interactive assistant that can listen to commands, perform basic tasks and answer general questions.

It started as a hands-on coding project and is also a way to explore how different technologies can work together in a real-world application.

## ✨ What Can Jarvis Do?

- 🎙️ **Voice Recognition** – Listen to and recognize spoken commands.
- 🟢 **Wake Word Detection** – Activate the assistant by saying "Jarvis".
- 🔊 **Voice Responses** – Respond with generated speech.
- 🌐 **Website Automation** – Open Google, YouTube, Facebook and LinkedIn.
- 🎵 **Music Playback** – Play songs using predefined music links.
- 📰 **News Updates** – Fetch and read the latest Indian news headlines.
- 🧠 **AI Conversations** – Generate intelligent responses using Google Gemini.

## 🚀 Getting Started

Follow these steps to run Jarvis on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/krankur897/Jarvis-Voice-Assistant.git
```

### 2. Enter the Project Directory

```bash
cd Jarvis-Voice-Assistant
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure API Keys

Create a `.env` file in the project directory and add your API keys:

```env
GEMINI_API_KEY=your_gemini_api_key
NEWS_API_KEY=your_newsapi_key
```

Use your own API keys. Keep this file private and never upload it to GitHub.

### 5. Start Jarvis

```bash
python main.py
```

🎉 You're ready to interact with Jarvis!
